## 🌱 IPO Chart – Garden Catalog Web Application

### Inputs
- Location Data (ZIP code or GPS coordinates)
- User Preferences (plants, animals, land use)
- Garden Parameters (size, soil type, irrigation)
- External Data Sources:
  - USDA Plant Hardiness Zones
  - Weather Data (NWS / OpenWeather)
  - Soil Data (SSURGO / Web Soil Survey)

### Processing
- Geolocation and hardiness zone lookup
- Weather forecast and frost risk analysis
- Soil data retrieval and analysis
- Plant suitability evaluation
- Garden planning and calendar generation
- Acreage calculations for plants and animals
- Persistence of user and garden information

### Outputs
- Actionable planting recommendations (plant now, start indoors, wait)
- Personalized garden calendar
- Soil and land suitability report
- Acreage and land planning estimates
- User dashboard with saved gardens and progress tracking
